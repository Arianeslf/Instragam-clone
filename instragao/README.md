# 🌾 Instagrão: o Espelho dos Desejos

![Instagrão Banner](https://via.placeholder.com/800x200/000000/f5f5f5?text=INSTAGRÃO+%F0%9F%8C%BE)

> Projeto desenvolvido para fins educacionais como clone visual inspirado na interface do Instagram, com identidade própria.

---

## 📖 Descrição

O **Instagrão** é uma recriação visual da tela inicial do Instagram em dark mode, feita com React + Vite, com foco educacional. Apresenta uma mistura de temas: rock 🎸, gatos 🐱, anime Studio Ghibli ✨, The Office 😏, vendas 💰 e tecnologia 💻.

---

## 🛠️ Tecnologias

- **React 18** — componentes, useState, props, eventos
- **Vite** — bundler e dev server ultra-rápido
- **CSS puro** — variáveis CSS, flexbox, responsividade
- **JavaScript ES6+** — arrow functions, destructuring, spread

## 🚀 Como rodar

### Pré-requisitos
- Node.js 18+ instalado
- npm ou yarn

### Passos

```bash
# 1. Entre na pasta do projeto
cd instragao

# 2. Instale as dependências
npm install

# 3. Rode o servidor de desenvolvimento
npm run dev

# 4. Acesse no navegador
# http://localhost:5173
```

### Build para produção
```bash
npm run build
npm run preview
```
