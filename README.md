# 📸 Instagrão

Clone visual do Instagram desenvolvido com React para fins educacionais e prática de front-end.

---

#  Sobre o Projeto

O Instagrão é um projeto inspirado na interface do Instagram, criado para praticar:

- React
- Componentização
- Responsividade
- Layout moderno
- CSS
- Estruturação de interfaces

O projeto reproduz elementos clássicos da plataforma como:

✔️ Stories  
✔️ Feed de postagens  
✔️ Sidebar lateral  
✔️ Sugestões de usuários  
✔️ Dark Mode  
✔️ Interface responsiva

---

#  Tecnologias Utilizadas

- React
- Vite
- JavaScript
- HTML5
- CSS3

---

#  Funcionalidades

- Barra lateral fixa
- Stories com borda gradiente
- Feed estilo Instagram
- Sugestões de perfis
- Layout responsivo
- Interface dark mode
- Componentes reutilizáveis

# ⚙️ Como Rodar o Projeto

Clone o repositório:

```bash
git clone https://github.com/seuusuario/instagrao.git
```

Entre na pasta:

```bash
cd instagrao
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
